Amazon Clone

A front-end Amazon clone website built using HTML and CSS to practice and demonstrate web development fundamentals.

📌 About the Project

This project recreates the look and feel of an Amazon-style e-commerce website using only HTML and CSS. It was created as a learning project to improve my understanding of webpage structure, styling, layouts, and responsive design.

🚀 Features

Amazon-inspired navigation bar

Search bar UI

Product/category sections

Product cards

Promotional/banner sections

Footer with multiple sections

Clean and structured webpage layout

Responsive styling (if supported by the project)

🛠️ Technologies Used

HTML5 – Website structure and content

CSS3 – Styling, layouts, colors, spacing, and design

💻 How to Run

Download or clone this repository.

Open the project folder.

Open index.html in your browser.

You can also use the Live Server extension in VS Code for a better development experience.
